# Security policy

## Reporting a vulnerability

Do not open a public issue. Email **[security@moqom.cloud](mailto:security@moqom.cloud)**
with:

- a description of the issue and its impact,
- steps to reproduce, or a proof of concept,
- the affected component (SDK version, sample, API, relay),
- your name or handle if you would like credit.

Please do not include real users' personal data in a report.

We aim to acknowledge reports within 3 business days. The full policy, including
scope and safe harbour, is at
[moqom.dev/security/disclosure](https://moqom.dev/security/disclosure/).

**Bug bounty:** a HackerOne program is coming soon; this file will link to it
when it opens. Until then, email is the only channel.

## Scope

This repository's source (the package manifest, `MoqomUI`, the sample app and
the build scripts) and the prebuilt frameworks attached to its releases.

## Supported versions

Fixes ship in the next release. Until 1.0, only the latest release is supported.
